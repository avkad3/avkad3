### 🚀 Featured Projects

**[ContextMesh](https://github.com/avkad3) — Offline-First Peer-to-Peer Mesh Chat**
Production-grade distributed chat app in Go — real-time messaging, offline sync, multi-hop mesh networking, E2E encryption, and conflict-free message sync. Built on WebSockets, PostgreSQL, Redis, and Docker.
`Go` `WebSockets` `PostgreSQL` `Redis` `Docker`

**[NeuralScript](https://github.com/avkad3) — Custom AI Domain-Specific Language**
A Python-like DSL that abstracts neural network training, RAG pipelines, and LoRA fine-tuning, with built-in `think` blocks for AI reasoning and a custom parser for datasets, architectures, and knowledge bases.
`Python` `Custom Parser`

**[PyCodeAtlas](https://pypi.org/project/pycodeatlas/) — Published on PyPI (1,000+ downloads)**
Static code analysis CLI that builds dependency graphs and detects dead code using Python AST and NetworkX.
`Python` `AST` `NetworkX` `SQLite`

**[Multi-Agent AI Research System](https://github.com/avkad3)**
Orchestrates LangGraph stateful agents with CrewAI task delegation for automated research and synthesis, deployed via FastAPI.
`LangGraph` `LangChain` `CrewAI` `FastAPI`

**[Orbital Maneuver RL](https://github.com/avkad3)**
Custom Gymnasium environment for fuel-efficient orbital transfers — a PPO agent trained over 500K steps that beat classical Hohmann transfer by 12% fuel efficiency.
`Python` `Gymnasium` `Stable Baselines3` `PPO`

**Demand Forecasting Platform**
Multi-horizon forecasting with confidence intervals across 34,000+ product-plant series, cutting stock-out rates by 22%. Built during my internship at SAVIC Technologies.
`PyTorch Forecasting` `TFT` `LightGBM` `Streamlit`

**GR-IR Reconciliation QA Agent**
RAG-based QA system over ChromaDB and Azure OpenAI answering GR-IR reconciliation questions at 94% semantic accuracy.
`FastAPI` `Azure OpenAI` `LangChain` `ChromaDB`

**Restaurant Reservation System + RCAE**
AI-assisted reservation platform with a Reservation Conflict Anticipation Engine, cutting overbooking incidents by 30%. RCAE is [published on Zenodo (CERN)](https://doi.org/10.5281/zenodo.21477811).
`FastAPI` `React` `SQLite`
